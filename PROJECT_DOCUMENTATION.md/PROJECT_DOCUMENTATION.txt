# Smart Video Management System (VMS)

## 1. Project Overview

Smart Video Management System (VMS) is an AI-assisted surveillance application designed to monitor CCTV footage and identify intrusion events.

The system provides a unified dashboard where users can view recorded camera footage, monitor AI-detected events, and review event information.

The prototype uses one CCTV camera, Camera 01.

## 2. Objectives

The main objectives of the project are:

- Display CCTV camera footage.
- Provide video playback.
- Detect people using AI.
- Identify intrusion in a configured restricted zone.
- Record detected events.
- Display event timestamps.
- Display confidence scores.
- Display the camera and detection zone.
- Provide a dashboard for surveillance monitoring.

## 4. System Architecture

The system consists of three major components:

1. Frontend
2. Backend API
3. AI Detection Engine

The frontend communicates with the FastAPI backend using HTTP requests.

The AI detection engine processes the CCTV video and detects people entering the configured restricted area.

Detected events are sent to the backend and stored in the SQLite database.

## 5. Working Process

1. Camera 01 video is loaded into the system.
2. The AI detection engine reads the video frame by frame.
3. YOLO detects people in the video.
4. The system checks whether a detected person enters the configured restricted zone.
5. If an intrusion is detected, an event is generated.
6. The event contains:
   - Camera ID
   - Event type
   - Timestamp
   - Confidence
   - Detection zone
7. The event is sent to the FastAPI backend.
8. The backend stores the event in SQLite.
9. The frontend retrieves the events from the API.
10. Events are displayed on the dashboard.

## 7. Detection Zone

A restricted detection zone is configured for Camera 01.

The system generates an intrusion event when a detected person enters the configured restricted area.

This helps reduce irrelevant detections outside the monitored region.

## 8. Dashboard

The dashboard provides:

- Storage information
- Event information
- Video playback

## 9. API

The backend provides an API endpoint for retrieving events.

GET:

`/events`

The detection engine uses:

POST:

`/events`

to submit newly detected events.

## 10. Database

SQLite is used to store detected events.

Each event contains:

- ID
- Camera ID
- Event type
- Timestamp
- Confidence
- Zone
- Created time
